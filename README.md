# 📊 Statistics for Data Science and ML

A daily learning log documenting my journey through statistics concepts essential for Data Science and Machine Learning.

## 📌 About This Repository

This repo is my personal space to track and share what I learn about statistics every day — from foundational concepts to advanced topics — as I build a strong base for a career in Data Science and Machine Learning.

Instead of just consuming content, I upload here to:
- Reinforce my learning through notes, code, and examples
- Keep a consistent daily learning streak
- Track my progress over time
- Create a resource I (and others) can revisit anytime

## 🎯 Goals

- Build a solid foundation in statistics for DS/ML
- Practice concepts with real code (Python/R)
- Stay consistent with daily learning
- Document everything in a clear, organized way

- Probability Theory & Distributions
- Inferential Statistics
- Hypothesis Testing
- Correlation & Covariance
- Confidence Intervals
- Central Limit Theorem
- Sampling Techniques
- Regression Analysis
- A/B Testing
- Bayesian Statistics
- Statistical concepts used in ML algorithms
